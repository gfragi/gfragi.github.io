Work connected to the Horizon Europe project **APPtake** (GA 101128082), with E. Filiopoulou and G. Dede.

The aim is to turn a compliance-oriented IT security risk methodology (ITSRM²) into a **decision-support system for security investments**: which combination of controls gives the best return under a budget?

The framework combines:

- multi-period, discounted **Return on Security Investment (ROSI)**
- **multi-objective optimisation** (NSGA-III) to produce Pareto-optimal control portfolios
- **Monte Carlo stress testing** of the recommended portfolios

It is validated on a real organisational risk-assessment dataset. A paper is in preparation.
